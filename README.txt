- preview.png

Repository: aurelion-website/razzo_alberto

Dopo il commit, attendi qualche minuto per la pubblicazione di GitHub Pages. WhatsApp può mantenere in cache la vecchia anteprima: per forzare una nuova scansione, prova a condividere una volta:
https://aurelion-website.github.io/razzo_alberto/?v=2

Dopo l'aggiornamento della cache, puoi tornare a condividere l'URL pulito.
